Website: https://www.modelportglobal.com/

## Hosted Gateway

### ModelPort Global

ModelPort Global is a unified AI API gateway for connecting applications to multiple model providers through familiar API patterns.

- Website: https://www.modelportglobal.com/
- Pricing: https://www.modelportglobal.com/pricing
- Dashboard: https://www.modelportglobal.com/dashboard
- Model coverage: DeepSeek, Qwen, GLM, Claude, GPT, and other account-enabled models

Best for:

- Developers who want a quick OpenAI-compatible endpoint
- Teams that need model routing and usage tracking
- Apps that need one integration layer for multiple model providers

### AI Router

AI Router is an OpenAI-compatible ChatGPT API relay for developers.

- Website: https://ai-router.dev
- API base URL: https://api.ai-router.dev/v1
- Localized pages: `/cn`, `/ru`, `/fa`, and other site locales
- User-facing hooks: API keys, usage tracking, token/cost visibility
- Onboarding: `20U` total for new users, with `5U` on signup and `15U` unlocked after top-up

Best for:

- Developers who want a low-friction OpenAI-compatible endpoint
- Teams that need per-key usage visibility
- Short testing cycles with daily or weekly plans

## Choosing A Gateway

Consider these factors:

- API compatibility with your current SDK
- Supported model providers
- Usage dashboard and billing transparency
- Rate limit controls
- Team and key management
- Uptime and latency requirements
- Compliance with provider terms

## Responsible Use

Use gateways only with authorized API access and permitted workloads. Do not use gateway software or hosted services to bypass provider terms, safety systems, or account restrictions.
